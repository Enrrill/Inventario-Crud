# Css

## Tema de color: rojo brillante con blanco suave/negro profundo
El sistema usa un tema de color personalizado: modo claro con fondo blanco cálido suave y rojo brillante (oklch 0.62 0.25 25) como color primario; modo oscuro con fondo negro profundo (oklch 0.10 0.005 260) y rojo brillante (oklch 0.65 0.25 25). El progreso de Inertia usa #E53935. Los tokens CSS definen --primary, --ring, --sidebar-primary y --destructive en rojo.
